# 👋 Welcome to the Exploration Toolkit

**Exploration Toolkit is a Unity asset which provides many exploration-related systems to add to your game.**

There's a lot this toolkit has to offer, so it may be overwhelming to know where to start. Here's my list of learning resources in order of what I think is most useful for someone learning the ropes:

1. Check out the [multi-part tutorial series on YouTube](https://www.youtube.com/playlist?list=PL7QZMl1mSodk7QgdeduMBVBzTE5YeZBIA), where I walk through each system, how to implement them, and how they work.

2. There are demo scenes for each of the toolkit's systems. Find these in the `Exploration Toolkit > Implementation > Demos > Showroom > Scenes` folder.

3. This documentation!
